# Temporal Data Conventions

| Category | Convention |
| --- | --- |
| Time Standard | UTC |
| Time Stamp Format | YYYY-MM-DDTHH:MM:SSZ|
| Timestamp precision | Microseconds (0.000001)|

## Standard Attributes
- Observation time: `observed_at`
- Record creation time: `created_at`
- Temporal validity: `valid_from`, `valid_to`
